# 📊 Inventory Management Dashboard

## 📌 Project Overview

An interactive **Inventory Management Dashboard** developed using Microsoft Excel to monitor sales, inventory, purchase orders, and supplier performance.
The dashboard provides an easy-to-use interface for analyzing inventory-related business information through interactive charts, slicers, form controls, and VBA automation.
---
## 🎯 Business Objective

The objective of this project is to create a centralized dashboard that helps users:

- Monitor inventory status
- Track purchase order status
- Evaluate supplier performance
- Analyze monthly sales trends
- Compare sales across product categories
- Filter the dashboard using different time periods
- Quickly understand important inventory and sales information

## 📊 Dashboard Features

### 1. Monthly Sales Trend

Displays the trend of sales across different months to help identify changes in sales performance over time.

### 2. Sales by Category

Provides a visual comparison of sales across different product categories.

### 3. Inventory Status

Shows the current inventory status and allows users to view inventory-related information interactively.

### 4. Purchase Order Status

Displays purchase order information based on different statuses such as:

- Approved
- Cancelled
- Pending
- Received

### 5. Supplier Performance

Provides a visual representation of supplier-related performance.

### 6. Interactive Slicers

The dashboard includes interactive slicers, including:

- Year-Month
- Product Name
- Sales by Category

These slicers allow users to filter the dashboard dynamically.

### 7. VBA Automation

VBA is used to control the dashboard charts through interactive buttons.

The dashboard contains three chart-selection buttons:

- Inventory Status
- Purchase Order Status
- Supplier Performance

Selecting a button displays the corresponding chart while hiding the other charts.

## 📈 Dashboard Interactivity

The dashboard combines **Slicers + Form Controls + VBA** to provide an interactive user experience.

Users can:

1. Select a time period.
2. Filter products.
3. Filter sales categories.
4. Select Inventory Status.
5. Select Purchase Order Status.
6. Select Supplier Performance.
7. View the corresponding chart dynamically.

## 🚀 How to Use

1. Download the Excel `.xlsm` file.
2. Open the file using Microsoft Excel.
3. Enable macros if Excel asks for permission.
4. Use the slicers to filter the dashboard.
5. Use the dashboard buttons to switch between:
   - Inventory Status
   - Purchase Order Status
   - Supplier Performance
